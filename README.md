# 🔳 QR Code Generator

## 📖 Overview
This project generates QR codes from user input such as text or URLs. It allows users to create and download QR codes easily.

---

## ⚙️ Features
- Generate QR code from text or URL  
- Download QR code as image  
- Simple and user-friendly interface  

---

## 🛠️ Tech Stack
- Language: HTML, CSS, JavaScript
